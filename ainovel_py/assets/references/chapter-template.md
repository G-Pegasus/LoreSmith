# 章节组织模板

模板不是固定格式，只是一种检查章节是否有呼吸的方式。可以打破顺序，但不要失去变化。

## 1. 入口

- 从一个动作、异常细节、未完成对白或具体场景进入。
- 不急着解释大背景，先让读者知道此刻谁在承压。
- 入口最好带一个小问题：为什么他停下，为什么她不回答，为什么这里和上次不同。

## 2. 试探

- 人物先用低成本方式接近目标：问一句、看一眼、藏一个动作。
- 让对方或环境给出不完全回应。
- 这一段的重点是制造不确定，不是立刻给答案。

## 3. 升级

- 压力变具体：证据出现、谎话露缝、关系被迫表态、危险靠近。
- 人物要做选择，哪怕只是沉默、撒谎、递出东西或离开。
- 选择要带后果，不能只是顺着大纲往前走。

## 4. 回声

- 给读者一点情绪停留。一个物件、一种气味、一句没说完的话，都可以成为回声。
- 回声可以承接上一章，也可以反衬本章变化。
- 不要把回声写成主题总结。

## 5. 出口

- 出口要打开下一步：行动、误会、关系变化、信息矛盾或情绪未落。
- 不一定要大反转，但要让读者觉得人物已经不能回到本章开头。
- 章末句子尽量具体，少用抽象升华。
